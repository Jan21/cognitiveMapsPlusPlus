What we actually achieved

Two results that hold up, and one honest limit. An embedding trained only on which moves are legal encodes a state space whose local dimension matches the true degrees of freedom. A gated encoder then learns to make that dimension readable from the embedding's own geometry. Here is exactly how far that goes, and where it still leans on a crutch.

The setup

A world with a knob on its degrees of freedom

Agents sit on a torus grid. Each agent carries a knob that sets which moves it can make: both axes (2 DOF), one axis (1 DOF), or frozen (0 DOF). The knob can be flipped only when the agent is standing on that knob's control cell, so far from the control cell you are genuinely locked into your current movement mode. The knob's value is always visible as a pixel the agent never stands on.

That gating is the whole point: it manufactures states of truly different local dimension in one shared space. A configuration of four agents can have total DOF anywhere from 0 to 8. The model never sees the DOF label. It is trained on adjacency alone: a multi-scale isometry loss on legal moves (embedding distance should equal flat-torus geodesic distance), gated flip edges at distance 1, and a repulsion term to keep far states far.

Result 1 · solid

The environment makes genuinely low-dimensional states, and the embedding reads them

First, the states are real. A frozen agent sitting far from its control cell contributes exactly zero dimensions: a "one agent free, one agent frozen" state reads local dimension ~2.1, that is, only the free agent. This is not an artifact of measurement; the gating truly removes degrees of freedom.

Second, an image-trained embedding recovers them. We read local dimension at a chosen state by embedding only that state's legal neighbourhood (exact BFS enumeration of the legal ball) and taking the correlation-dimension slope. No global projection, no UMAP. Pure-movement 2D and 4D states separate with a clean factor-2 gap (2.1 vs 4.3), and the full DOF ladder from 0 to 8 comes out monotone and separated.

The one caveat on Result 1 This measurement uses the graph. The neighbourhood is defined by BFS over legal moves, so we are partly measuring the transition graph, not the embedding's geometry alone. That is a real result about a learned map, but it is not yet "the embedding space is stratified on its own."

Result 2 · the hard question · honest negative

Drop the graph, and the image embedding forgets the strata

The interesting claim is stronger: can local dimension be read from the embedding's own nearest neighbours, with no graph at all? For the image encoder, the answer is no. Building a neighbourhood by jittering all agents and taking the k nearest in embedding space returns dimension ~8 flat, for every DOF and for the junctions.

The reason is precise. The isometry loss only supervised legal moves, so the image encoder maps any small pixel move, legal or not, to a small embedding move. Displacing a frozen agent was never pushed apart. So the embedding is locally almost isometric to the full 8-D position space, and Euclidean k-NN reads that ambient 8 everywhere. The gate lived in the graph, never in the metric.

We pinned this on fully enumerable minimal harnesses rather than guessing. One agent on an 8x8 torus (192 states, all embedded) showed the embedding does respect a single illegal step (an illegal row move reads 5.65 vs a legal column move 1.09). Two agents showed the smoking gun: the legal ball reads 2.25 (correct), but a graph-free jitter pool reads 5.98. The embedding was fine; the graph-free measurement leaks. A negative result that located the bug exactly is the useful kind.

Result 3 · the fix · solved

A knob-gated encoder learns to make the metric itself stratified

To fix the metric you must collapse the immovable coordinates (quotient them away), not merely repel illegal moves. An ideal pre-check confirmed the fork: collapse-distance tracks DOF, repel-distance is non-monotone garbage graph-free. And crucially, collapse cannot be bolted on as a loss over an image encoder; the image encoder will not stop reading a frozen agent's pixel.

It has to live in the encoder structure. A factored encoder builds one token per agent (agent id + knob + row + column) and gates each agent's row and column contribution by its knob. Freeze an axis and that axis leaves the representation entirely. The result:

Two things matter here. First, d_illegal, the embedding distance produced by moving a frozen agent, is 0.00: the embedding is literally invariant to immovable coordinates, so its own geometry is stratified. Second, the learned gate (a sigmoid the network trains on adjacency) matches the hardwired gate almost exactly. The model is not told which axes to drop; it learns to drop them. That is the genuine "the embedding space is stratified" result, and it holds graph-free across the whole ladder 1 to 8.

The honest caveats on Result 3 Three things keep this from being a blank-check claim. (1) The clean low-DOF read uses an axis-guided pool: the neighbourhood is jittered along knob-allowed axes, which peeks at the observable knob. The fully-generic pool tracks DOF 3–8 on its own; the lowest one or two strata still need that hint. (2) The factorization is an architectural prior: we hand the model a per-agent, per-axis representation, and it learns the gating within that. The image encoder, with no such prior, could not. (3) DOF 8 reads 9.1, a mild overshoot from correlation-dim noise on a small curved patch. So: the metric is genuinely stratified, but the cleanest dimension read still relies on knowing the knob.

The bottom line

What we can and cannot claim

Can claim

  • A gated environment manufactures states of genuinely different local dimension in one shared space; a frozen agent contributes exactly 0 DOF.
  • An embedding trained only on adjacency recovers the full DOF ladder 0–8 to the finite-sample ceiling, using a graph-defined local ball. No UMAP, no dimension labels.
  • A factored knob-gated encoder makes the embedding's own metric stratified: it is invariant to immovable coordinates (d_illegal = 0.00), so dimension is readable from embedding neighbours without the graph.
  • That gating is learned from adjacency, not hand-set: the learned gate matches the hardwired upper bound.

Cannot claim (yet)

  • That a plain image embedding is stratified on its own. It is not; graph-free k-NN reads ambient 8 everywhere.
  • A fully blind, knob-free graph-free dimension read at the lowest strata. DOF 1–2 still need a knob-guided pool; only DOF 3–8 come out of a generic pool unaided.
  • That any architecture self-stratifies. The result needs the factored per-agent, per-axis prior; the collapse must be structural, not a loss.
  • Exact dimension at the top of the ladder. High DOF compresses (graph ball) or mildly overshoots (graph-free), both expected from finite samples.

The single sentence: an embedding can be trained so that its geometry, not just its graph, respects the constraints of the state space, and the model learns which degrees of freedom are live rather than being told. The honest asterisk is that reading the very lowest strata cleanly still uses the observable knob.
