Attention as a sum, not an average

A distance between two states, built so it can accumulate costs the way a real path does: dial a knob up, move, dial it back. The fix that made it work: independent gates and a genuine sum.

exact on the 60×60 geodesic · RMSE 0.00

The formula

d(x, y) = Σ terms t    sigmoid(q · kt)  ×  softplus(valuet) ⌃  gate in [0,1], per term ⌃  a distance ≥ 0

Each term contributes its own gated distance, and the terms are added. The gate decides whether a term is active for this pair of states; the value is how much it costs.

Why the sum, not softmax

softmax (old, broken)
Weights are forced to sum to 1 → the output is a weighted average. An average can never exceed its largest term, so it cannot build up a detour.
independent sigmoids (attn_sum)
Each gate is its own [0,1], no competition → the terms accumulate. Two, three, many costs can stack into one distance.

Three terms

  • knob term — cost of dialing the knob: ∥Δknob∥.
  • position term — cost of moving the agent: ∥Δpos∥.
  • detour term — the extra cost to enable a move. Its value is a function of both knobs, and its gate fires only when the position actually changes. This is the piece a plain gated distance cannot add.

The learned distance is effectively:

d ≈ ∥Δknob∥ + ∥Δpos∥ + [Δpos > 0] · ( (5−kx) + (5−ky) )

Worked example

Knob 5 means the agent can move; any other value freezes it. To go from (pos 0, knob 0) to (pos 5, knob 0) you must dial up to 5, move 5, dial back: 15. The terms add up to exactly that.
