A map that changes dimension

A model that sees only a picture of the world — four agents and their movement settings drawn as pixels — learns an embedding whose local dimension changes from place to place. And because an agent can only change how it moves while standing next to its own switch, some states are genuinely stuck: read the dimension straight off the map and it climbs the whole ladder, from 1 up to 8.

01 — What the model sees

A state, drawn as an image

Four agents live on a 24×24 wraparound grid. Each has a knob setting how it may move — all (2-D), horizontal or vertical (1-D), or none (frozen, 0-D) — so a state's local dimension is the four knobs' dimensions added, from 0 up to 8.

The model is handed none of this as numbers. It gets a picture: each agent painted as its own pixel value on the grid, plus a few cells off to the side whose value spells out each agent's current knob. Everything the model knows, it has to read out of the image.

The gate — and why it matters A knob can be flipped only when its agent stands on that knob's control cell. Far from every switch, you cannot change how you move — so the neighbourhood really is just the current movement, and a frozen agent out there contributes a genuine zero. The knob's value lives in its own always-visible pixel that no agent can step onto, so it never gets hidden; and we never sample a dead state (everyone frozen with nobody at a switch).

02 — Model

Attention reads the picture; a norm makes it a map

Each pixel becomes a token — its value plus its position. Learned query slots attend over the pixels and pool them into a state embedding e(s) ∈ R⁶⁴. The learned distance is a norm of the difference:

D(u, v) = ‖ e(u) − e(v) ‖2 # norm ⇒ a real metric emerges

Reading distance as a norm — not a free scalar — is what makes a consistent, navigable geometry appear from purely local training. Sixteen query slots give the encoder enough heads to locate all four agents and read all four knobs off the image at once.

03 — Training

Only local adjacency

No shortest paths, no rewards, no actions — only which states are one step apart. Three terms, all sampled on the fly:

  • Isometry. Nearby states (within an agent's allowed axes) are anchored to their exact flat-torus geodesic √Σ offset², over a range of scales — so adjacent states stay one apart instead of collapsing, and local patches come out flat, each stratum keeping its true dimension.
  • Gated knob edges. A knob-flip is a single step, anchored to distance 1 — but only from a state where the agent is on its control cell. Switching movement-mode costs the same as a move, yet you can only do it in the right place.
  • Repulsion. Random pairs are pushed apart so the space can't collapse.

The full four-agent space is over a hundred million states; it is never enumerated — every pair is drawn on the fly, and the run finishes in well under an hour on a single GPU.

One connected map, but locally stuck Globally the map is one connected piece — a flip still costs a single step, so no state is an island. But that flip is only available at a control cell. Everywhere else you are locked into your current movement mode, which is exactly why a state far from every switch can be honestly low-dimensional — and why a control cell, where modes can change, becomes a higher-dimensional junction.

04 — Reading the dimension

Up the whole ladder

The stratification is a local property, so we measure it locally — and only locally. We never project the whole space (no UMAP, no PCA). Around a chosen state we enumerate just its local neighbourhood by legal moves, embed only those points, and count how many fall within a growing radius: on a d-dimensional stratum that count scales as rd, so its growth rate is the local dimension.

The junction at a control cell reads ≈ 2 where the fully-frozen bulk would be 0.

05 — In short

A picture is enough

  • Trained on images and local adjacency alone — no coordinates, no actions — the model learns a connected map of a hundred-million-state space.
  • That map is stratified: its local dimension varies from place to place, tracking each state's degrees of freedom monotonically up the full 1 → 8 ladder, recovered from local neighbourhoods with no global projection.
  • Because mode-switching is gated to control cells, some states are genuinely low-dimensional, and control cells stand out as higher-dimensional junctions where strata meet.
