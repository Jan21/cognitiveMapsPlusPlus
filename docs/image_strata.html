01 — What the model sees

A state, drawn as an image

Two agents live on a 15×15 wraparound grid. Each has a knob setting how it may move — all (2-D), horizontal or vertical (1-D), or none (frozen, 0-D) — so a state's local dimension is the two knobs' dimensions added, from 0 up to 4.

The model is handed none of this as numbers. It gets a picture: each agent painted as its own pixel value on the grid, plus two little cells off to the side whose value spells out each agent's current knob. Everything the model knows about the state, it has to read out of the image.

02 — Model

Attention reads the picture; a norm makes it a map

Each pixel becomes a token — its value plus its position. Eight learned query slots attend over the pixels and pool them into a state embedding e(s) ∈ R⁴⁸. The learned distance is a norm of the difference:

D(u, v) = ‖ e(u) − e(v) ‖2 # norm ⇒ a real metric emerges

Reading distance as a norm — not a free scalar — is what makes a consistent, navigable geometry appear from purely local training. The query slots give the encoder enough heads to locate both agents and read both knobs off the image at once.

03 — Training

Local moves, expensive mode-switches

No shortest paths, no rewards, no actions — only local adjacency, with three terms:

  • Isometry. Nearby states (within an agent's allowed axes) are anchored to their exact flat-torus geodesic √Σ offset², over a range of distances. Local patches come out flat, so each stratum keeps its true dimension.
  • Expensive knob-changes. Flipping a knob is a real change of mode, so it's anchored to a large distance rather than one step. This is the key to the picture: it pushes the sixteen configurations apart into distinct clusters instead of gluing them into one blob.
  • Repulsion. Random pairs are pushed apart so the space can't collapse.

Every training pair is sampled on the fly, so the ~800,000-state space is never enumerated — and the whole sweep runs in minutes on a single GPU.

Why the mode-switch cost matters With knob-changes cheap, a 4-D state and its 3-D neighbour sit on top of each other and the strata smear together. Making the switch expensive separates them — and only then does the stratified structure become visible, one clean island per configuration.

04 — And the dimension is right

Each island is the size it should be

Separation is only half the story; each cluster should also have the correct local dimension. Measuring with the volume-growth method — count neighbours within a growing radius, count ∝ rd — the estimate tracks the true degrees of freedom, up to correlation 0.93 across strata. The frozen configurations read near 0; the fully-free one reads near 4.

05 — In short

A picture is enough

  • Trained on images and local adjacency alone, the embedding organizes into sixteen clean strata, one per movement-configuration.
  • Each stratum has the right local dimension (0–4), read back by volume growth at correlation up to 0.93.
  • The trick that makes the strata visible is treating a knob-change as an expensive transition, so configurations of different dimension pull apart instead of smearing together.
