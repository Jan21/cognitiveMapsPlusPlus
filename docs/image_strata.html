01 — What the model sees

A state, drawn as an image

Two agents live on a 15×15 wraparound grid. Each has a knob setting how it may move — all (2-D), horizontal or vertical (1-D), or none (frozen, 0-D) — so a state's local dimension is the two knobs' dimensions added, from 0 up to 4.

The model is handed none of this as numbers. It gets a picture: each agent painted as its own pixel value on the grid, plus two little cells off to the side whose value spells out each agent's current knob. Everything the model knows about the state, it has to read out of the image.

02 — Model

Attention reads the picture; a norm makes it a map

Each pixel becomes a token — its value plus its position. Eight learned query slots attend over the pixels and pool them into a state embedding e(s) ∈ R⁴⁸. The learned distance is a norm of the difference:

D(u, v) = ‖ e(u) − e(v) ‖2 # norm ⇒ a real metric emerges

Reading distance as a norm — not a free scalar — is what makes a consistent, navigable geometry appear from purely local training. The query slots give the encoder enough heads to locate both agents and read both knobs off the image at once.

03 — Training

Every step costs the same

No shortest paths, no rewards, no actions — only local adjacency, where a knob-flip is worth exactly the same as a position move. Three terms:

  • Isometry. Nearby states (within an agent's allowed axes) are anchored to their exact flat-torus geodesic √Σ offset², over a range of distances. Local patches come out flat, so each stratum keeps its true dimension.
  • Unit-cost knob changes. Flipping a knob is a single step, anchored to distance 1 — the same as moving an agent. Nothing about switching movement-mode is treated as special.
  • Repulsion. Random pairs are pushed apart so the space can't collapse.

Every training pair is sampled on the fly, so the ~800,000-state space is never enumerated — and the whole run takes minutes on a single GPU.

Not clusters — a field Because a knob-flip is just another unit step, a 4-D state and its 3-D neighbour sit right next to each other: the map is one connected piece, not a set of islands. The stratification doesn't live in how the embedding clusters — it lives in how its local dimension varies across that connected map, which is exactly what we measure next.

04 — Reading the dimension

Right on the diagonal

The stratification is a local property, so we measure it locally. Around each state, count how many neighbours fall within a growing radius: on a d-dimensional stratum that count scales as rd, so the growth rate is the local dimension. Done per state, the measured value lands almost exactly on the true degrees of freedom — the right panel above — at correlation 0.91.

05 — In short

A picture is enough

  • Trained on images and unit-cost local adjacency alone — no coordinates, no actions — the model learns a connected map of the state space.
  • That map is stratified: its local dimension varies from place to place, matching each state's degrees of freedom (0–4), recovered by volume growth at correlation 0.91.
  • No clustering required — a knob-change costs the same as a move, so the stratification shows up not as separate islands but as a dimension that changes across one connected map.
