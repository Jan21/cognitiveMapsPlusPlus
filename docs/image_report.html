the setup

One shared canvas, distinct markers

A state is drawn as a single GxG image: each of N agents is a distinct marker on the grid, plus a key token. Agent 0 is always free; agent j can move only when the key permits it; the key changes only when the mover reaches a control cell. So the true local dimension is 2 × (1 + #free), a ladder 2 / 4 / 6.

The encoder reads the image and emits one vector per component (agents + key) via per-component attention; the same gated L1 distance, multi-scale isometry training, and gate-guided VGT from the factored work then run on those vectors. The only new burden is binding: pulling each agent out of one shared picture.

the core result

The image encoder stratifies

This is the milestone. A frozen agent's one-pixel move reads far (13–62× a free move), a free move reads ~1 — extracted from a single shared canvas. That is exactly the failure the original monolithic image encoder had: it mapped any pixel move to a small embedding move and so read the ambient dimension everywhere. Per-component extraction plus the gated distance plus multi-scale isometry fix it.

the honest twist

The internals are entangled — but the measurement, not the binding, sets the ceiling

Inspecting the best 2-D model, the per-agent components are degenerate: position barely encoded (grid-adjacency 0.02–0.15), components collapsed to points, large cross-agent leakage. That entanglement is real. What it is not is the thing limiting the dimension readout — the control below shows a clean per-agent embedding reads about the same ladder. So the honest picture has two layers: the encoder's factors are messy, and separately, the volume-growth measurement is itself imperfect and is what actually caps the numbers.

A real tension, scoped narrowly One genuine tension survives: in 2-D, forcing hard deterministic binding lets the gate cheat (infer position from the clean components and cancel the isometry), giving a worse ladder than the entangled marker encoder. So you cannot simply demand clean binding and keep the readout. But this is about the gate, not about the image input adding apparent dimension — which, per the control, it barely does.
A control puts the blame where it belongs: the measurement The raw image ladder overshoots at the top and nans the lone mover, which looks like binding damage. A control settles it: swap the shared-canvas encoder for clean per-agent position embeddings and keep the distance, training, and measurement identical. The clean version overshoots almost as much (DOF-5 reads 7.2 vs the image's 7.8) and nans the lone mover too. So most of the overshoot is the volume-growth estimator inflating high-dimensional weighted-L1 balls, and the lone-mover nan is measurement discreteness at the thinnest stratum — not the image encoder. The genuine image-specific cost of reading a shared picture is small, roughly 0.3–0.6 of a dimension. The encoder sits close to the clean-factored ceiling; the ceiling itself is the imperfect part.
Seed variance The ladder is always monotone (correlation 1.0), but its absolute values swing with the random seed: DOF-4 reads anywhere from 2.8 to 4.6 across four seeds, DOF-6 more stably around 5.2–6.2. The single-seed “mae 0.3” was a lucky draw; typical error is 0.5–0.9. This loose calibration is consistent with the entangled black-box metric — the ordering is pinned down, the exact scale is not.
The lone-mover nan is a measurement artifact, not a gap The lowest stratum — a single always-free mover — nans at every setting, which looked for a while like a genuine failure. The control clears it too: the clean-embedding baseline nans it as well. A single free coordinate jittered by a window of W produces only about 2W+1 distinct gated distances, so the slope estimator has almost no dynamic range and returns nan. It is discreteness at the thinnest stratum, present with or without the image, and a tie-tolerant estimator or denser sampling would fix it. The higher strata stay clean and monotone.

the conclusion

Image input works — and sits close to the clean ceiling

Fed a single shared canvas, the recipe recovers the stratification the original image encoder could not, and its gate-guided VGT reads a monotone degrees-of-freedom ladder that scales to DOF-8 with more agents. A control probe reframed the caveats: the ladder's overshoot and the lone-mover nan are properties of the volume-growth measurement, reproduced by a clean per-agent embedding, not damage from reading a shared picture — the image-specific cost is only a fraction of a dimension. What stays genuinely open: the encoder's internal factors are entangled (interpretability, not accuracy), a hard-binding gate can still cheat in 2-D, the grid must grow with the agent count, and the dimension estimator itself wants a tie-tolerant replacement. So the harder input is handled — the map reads dimension from raw pixels, close to the best a clean factorization would give — and the remaining work is sharpening the readout, not the input.
