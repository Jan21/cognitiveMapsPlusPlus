Reading dimension from a learned distance

Train a distance the old cheap way, neighbours at distance one and everything else pushed away, then ask its own local geometry how many degrees of freedom a state has. With a gated attention distance it answers correctly. With plain Euclidean it cannot.

1 the environment

Three agents, a key that frees them

A state is (pos_0, pos_1, pos_2, key). Each agent lives on a 12-node cycle, a one-dimensional component. The shared key takes values 0 to 3. Agent i can move only when key > i, so the key controls how many agents are free, and therefore the local dimension of the state.

0none0 (dead)

3agents 0, 1, 23

Legal moves (each cost 1): step a free agent one cell along its cycle, or turn the key one notch (always allowed). Moving a frozen agent is illegal. The number of legal move directions at a state equals the key, which is exactly its degrees of freedom.

2 the distance model

A gated sum of per-component distances

The distance is not fixed; it is learned. Each component gets its own embedding table, and the distance is a weighted sum of per-component distances, where the weights come from the key through a small gate (this is the attention part):

d(x, y) = Σagents i wi(key) · ∥ ei(posix) − ei(posiy) ∥ + ∥ ekey(keyx) − ekey(keyy) ∥ wi = softplus( MLP( [ ekeyx+ekeyy , |ekeyx−ekeyy| ] ) )i # one weight per agent, from the key

It is a sum of L1 pieces, one per component. The gate w_i is the whole point: it lets the key decide how much each agent's displacement costs. If the gate learns to make a frozen agent's weight large, moving that agent becomes expensive, so it leaves the local neighbourhood. Plain Euclidean has no such gate: every agent's displacement always counts the same, which is why it stays blind to the key.

3 training

Local signal only: neighbour is 1, everything else is far

No shortest paths, no geodesic. We only teach the one-step structure and repel the rest. Per batch:

x # random state x' = one random LEGAL move from x loss += ( d(x, x') − 1 )2 # neighbour -> distance 1 x'' = move a FROZEN agent one step (illegal) loss += softplus( margin − d(x, x'') ) # push far r = another random state loss += softplus( margin − d(x, r) ) # push far margin = 15

That is the entire supervision. It never sees that two frozen positions are unreachable from each other; it only sees that the move is not a neighbour, so it repels it. From this the gate learns, on its own, to make a frozen agent's step expensive.

What the gate learned After training, a free agent's one-step distance is ~1 (as taught), while a frozen agent's one-step distance is 23 to 46 (repelled). The learned weights: w_free ≈ 0.25, w_frozen ≈ 5 to 8. The metric is now stratified: staying on the free directions is cheap, leaving them is a cliff.

4 the VGT measurement

How the neighbours are obtained

We want the local dimension at a probe state, read from the learned distance alone, with no graph. The subtle part is picking the neighbourhood. We do not use the transition graph, and we do not use a fixed count of nearest points. We let the metric select the neighbours:

  • Build a pool. Take the probe and make 60,000 copies, each with every agent jittered by up to ±5 cells on its cycle (the key is held fixed). Legality is never checked; the pool is a blind cloud around the probe.
  • Score by the learned distance. Compute d(probe, point) for every pool point. Because the gate makes frozen displacements expensive, points that jitter a frozen agent land far; points that only jitter free agents stay near.
  • Cut at the gap. Sort the distances. They are bimodal: a near free cluster, then a big multiplicative jump, then the frozen points. Take everything before the first big jump. That set is the neighbourhood, and the metric drew its boundary for us.
  • Read the dimension. On that free cluster, the VGT correlation dimension is the slope of log(rank) against log(distance). One free agent gives slope ~1, two give ~2, three give ~3.

The gated attention distance recovers the ladder, monotone and separated. Plain Euclidean on the identical training is flat near 2.7: with no gate it reads every agent's position as a real dimension, so it cannot tell a 1-DOF state from a 3-DOF one. The gate, and the fact that the metric repels illegal moves, is what turns the cheap local signal into a geometry whose own local dimension equals the degrees of freedom.

Honest caveat Dimension 1 reads 1.40, not 1.00, a mild overshoot from the curvature of a small 12-node ring. The ladder is clearly monotone and separated, but not razor sharp at the bottom; larger cycles would tighten it. The gap-cut is the load-bearing measurement step: a fixed count of nearest points overflows the tiny free cluster into frozen territory and inflates the dimension.
