Reading distance from pixels, without binding supervision

Can the recall-flow integrator read shortest-path distance from an image of the switchyard state, with no position labels? A weak encoder made it fail; porting the old gridworld CNN + cross-attention recipe made it the best model on image, unsupervised — up to a plateau just short of the supervised binding.

01The failure  weak encoder

The first image encoders rendered worker+crate onto an additive one-cell canvas and bound them with a single query-attention / value-match / slot. Unsupervised, the integrator capped at 0.73 and lost to the metric baselines (MRN 0.78, IQE 0.74) — the accumulator needs clean per-token binding, and the weak encoder could not provide it. Only an ugly auxiliary loss (decode the bound token to the true cell, using position labels) recovered it, to 0.88.

02The find

A past image distance model that worked well: gridworld/gw_probe.py (keys-&-doors world). It rendered the full scene to a multi-channel image, ran a CNN, and had each factor be a query token that cross-attends the CNN feature map. That generalized to unseen maps (0.14 MAE, xattn >> convpool). The missing ingredient in the switchyard attempts was the CNN spatial context.

03The win  CNN + cross-attention

Porting it (--enc image: render 8 channels → CNN → worker/crate query tokens cross-attend the feature map, no labels) lifts the integrator to 0.81 (map) / 0.84 (wire) and makes it the best model on image again — reversing the additive-canvas result.

04The plateau  honest ceiling

The last ~0.05 gap to the supervised 0.88 is not a capacity or training problem. Every lever tried — wider CNN (128), more heads (8), longer training (120k), deeper CNN (3-4 conv) — matches or hurts the simple 2-conv baseline. The unsupervised ceiling is ~0.85.

integ CNN xattn, held-out maps. The simple 2-conv w64 config is the sweet spot; bigger/deeper/longer do not beat it (deeper CNN hurts). Dashed = supervised 0.88.

Bottom line

The image-based integrator works without binding supervision once given a CNN + cross-attention encoder (the gridworld recipe), reaching 0.81-0.85 and beating the metric/symmetric baselines on both generalization axes. It sits just below the label-supervised 0.88, and that small gap is architecturally sticky — the accumulator's need for clean binding is the residual cost of dropping the labels.
