Two pictures in, one distance out: how the models work and how they score

Every model here sees only two rendered images, the start and the goal state of a switchyard, and must predict the exact number of moves between them. This page explains the current best image-only integrator end to end (learned slot perception, no hand-built object detector), the four baselines and the encoder search they were given, and the final results across seven levels of environment complexity on unseen maps and rewired causal structure (phase B′: 672 runs, 3 seeds everywhere, one setting per model tuned on the full switchyard).

metric:

1 · THE TASKDistance in a coupled world, from pixels

A 7×7 four-room yard. A worker pushes a crate; three gates sit in doorways and are open or closed; two levers toggle gates (one lever can flip several, XOR-wired); a pressure plate holds its gates open while the crate sits on it; a one-way chute admits the worker from one direction only. A state is (worker cell, crate cell, gate bits). The target is the true BFS shortest path length over the joint state graph. Train on 150 maps, test on 50 held-out maps (map split: new walls, positions, wiring) or on the same 200 layouts with the wiring resampled (wire split: rewired causality).

2 · THE INTEGRATORCurrent best recipe, stage by stage

python3 switchyard.py --train --enc pureimage --cnnk 1 --readout xattn --slots 16 --objch 1 --d 256 --layers 3 --T 4 \
   --heads 4 --cnnw 64 --cnndepth 2 --nmaps 200 --poolq 2000 --steps 80000 --lr 1e-3 --gradclip 1.0 --warmup 2000 --split map|wire
renderstate → image(B, 12, 7, 7)

Everything is drawn, nothing is told

Channels: walls · worker · crate · gate cells · gate-open bits · one channel per lever marking the lever and the gates it toggles (wiring as shared "colour") · plate + the gates it holds · four chute-direction channels. No coordinates, no ids, no adjacency, no wiring table.

objectness channel+1 input plane(B, 13, 7, 7)

One extra stencil: "something is here"

A plane that is 1 wherever any entity stencil is lit and 0 on empty floor and walls. It is a feature, not a mask: it is simply fed to the encoder like the other stencils, and every baseline gets it too. It says nothing about what is there.

1×1 encoderper-pixel MLP(B, 128, 7, 7)

No spatial mixing

Conv1×1(14→64) → ReLU → Conv1×1(64→128) → ReLU. A 3×3 CNN was the original failure: it blurred which entity lit which cell (gate bits, lever identity) into neighbours, and no amount of slot machinery could recover it (even supervised binding on 3×3 features scored 0.71). Per-pixel features keep every cell's channels exact; the transformer does the spatial reasoning.

16 slotslearned cross-attention(B, 16, 256)

Slots find the objects themselves

Sixteen learned query vectors each attend once over the 49 cell descriptions (softmax over cells) and read out a weighted average: one token per slot. Nothing is hard-wired about which slot binds what, and nothing tells the attention where to look; the diagnostic shows slots settling on the crate, on a gate together with its lever, etc. The only hint the model ever gets is the objectness input plane from the previous stage, which it is free to use or ignore. Without that plane the same model scores 0.843 / 0.852 at full complexity; with it 0.860 / 0.852 (0.869 / 0.878 in the dedicated sweep).

assemble3 copies(B, 48, 256)

Start · goal · anchor

[enc(start)+role₀ ; enc(goal)+role₁ ; enc(start)+role₂]. Only the first block will move; the goal and the start-anchor are re-injected unchanged at every pass ("recall"), so the network never loses its destination or origin.

recall loopT = 4 passesshared 3-layer block, d 256

Walk, and pay for the trip

cost = 0
for t in range(4):
    z    = Block(tok)                                  # 3 pre-norm transformer layers, d=256, 4 heads, same weights every pass
    cost = cost + (z[:, :16] − tok[:, :16]).norm(dim=-1).sum(-1)   # L2 length of each state token's move, summed
    tok  = [ z[:, :16] ; goal ; anchor ]              # keep the evolved state, re-inject goal + anchor
D = softplus(scale) · cost                             # one learned positive scalar; that is the whole head

Distance is the accumulated latent path length. The only way to output a large number is to actually move the state tokens far; the model cannot shortcut with a lookup.

trainingAdam 1e-3 · clip 1 · warm-up 2k · 80k

The "safe recipe"

Smooth-L1 to the BFS distance, batch 128, 150 training maps. Learning rate 1e-3 with gradient clipping and a 2k-step warm-up: at 2e-3 without clipping the slot/token read collapsed on some seeds (a token would never bind the worker and training plateaued at MAE ≈ 3). This recipe removed the bimodal seeds.

2½ · PERCEPTION, IN PLAIN WORDSStencils, per-cell descriptions, slots, and the one hint

The transformer that does the reasoning does not look at a picture; it looks at a short list of items. This is how the picture becomes that list.

The picture is a stack of stencils

The state is a stack of 12 black-and-white 7×7 stencils, one per kind of thing: worker, crate, gate cells, which gates are open, one stencil per lever marking the lever and the gates it toggles (that is how wiring is drawn), the plate with the gates it holds, four for the chute and its entry direction, and walls. We add a 13th: 1 wherever any entity stencil is lit, the "something is here" plane. It is the only hint, and the baselines receive it as well.

Each cell described on its own

A tiny network (two 1×1 layers) reads the 13 values of one cell and writes a 128-number description of that cell, without looking at neighbours. This matters: a 3×3 network blurred "closed gate at (3,5)" into "something gate-ish nearby", and that blur, not binding, was the original failure.

Slots pick out the objects

Sixteen learned query vectors each compare themselves to all 49 cell descriptions, softly weight the cells, and read out one averaged description: a token. Nothing says which slot takes which object and nothing steers the attention; the slots specialise by themselves during training (one on the crate, one on a gate together with the lever that toggles it, …). Sixteen slots per state go to the recall loop (start, goal, anchor = 48 tokens).

ablation: the hand-built alternative (fgpix)

We also tried replacing the slots by a fixed rule, "take exactly the lit cells as tokens" (plus explicit x/y coordinate planes). It scores about the same at full complexity (0.875 / 0.87 vs 0.86 / 0.85 for slots + objectness channel) but it is an object detector written by hand for this rendered world, where empty really means empty. We keep it as an ablation and do not use it for the main results or for any baseline.

3 · THE BASELINESSame tokens, different heads

Every baseline was given an encoder search on the full switchyard, then one setting per model for all rungs: encoder ∈ {12 learned slots (1×1), all 49 pixels via 1×1 (+coords), all pixels via a 3×3 CNN (depth 2–4, width 64/128, +coords)} × pooling ∈ {mean over tokens, flatten (keeps which-token-where)} × own transformer depth ∈ {0 = pure CNN→flatten→MLP, 2, 4, 6} × width ∈ {128, 256} × lr ∈ {5e-4, 1e-3, 2e-3}. Each state is encoded separately, then compared:

tokens → own transformer (0–6 layers, not shared) → mean-pool or flatten → Linear → f(s), f(g)

Two variants of every baseline appear in the results: its unconstrained best (IQE: 3×3 CNN → flatten, 2.0M params; sym: 1×1 pixels → flatten, 6.7M; scalar: 3×3 CNN → flatten → 4-layer transformer, 2.8M; MRN: slots, 0.7M) and its parameter-matched best (12 slots → 4-layer transformer → mean, 0.64–0.76M), each with and without the objectness channel. The integrator shown has 1.9M parameters; its 12-slot / d128 version (0.56M) leads the param-matched baselines at full complexity by about 0.05 as well. 6 · WHAT WE LEARNED

what carried the gains

1×1 encoder (identity per pixel; +0.13 at L2), the safe optimizer (no more bimodal seeds), slots ≥ entities and width d256 (+0.06 at L3), and the objectness input channel (+0.02–0.03 at L5). Each was found by a probe that could have killed it. The hand-built fgpix tokens reach the same level and are kept only as an ablation.

what did not

3×3 convolution, competitive iterative slot attention (all variants), reconstruction auxiliaries, attention-entropy sharpening, hard attention, slot-overlap penalty, slot LayerNorm, wire-path rendering, more maps, longer training, cosine decay, deeper block, more heads, mixed conv. And the supervised Hungarian binding ceiling on the 1×1 encoder is below the unsupervised model (0.77 vs 0.80–0.88): binding is no longer where the gap is.

status

Sections 4–5 are the final phase B′ run (2026-08-19): 672 runs, every model at one setting tuned on the full switchyard, 3 seeds, no hand-built object detector anywhere. Integrator rows at width 64; baselines at their own tuned widths.
