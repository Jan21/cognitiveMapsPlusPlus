1 · INPUTWhat one example is

A training example is a triple (x, g, m): start state, goal state, map id. States are yard.vec(s) (line 119): three integers

fieldtype / rangemeaning
x[0]int, index into yard.cellsworker position as a map-local cell index (cells = all non-wall cells plus the gap cells)
x[1]int, index into yard.cellscrate position, map-local
x[2]int in [0, 2ngate)gate bits; bit g = 1 means gate g is open (levers XOR wiring masks into these bits; the plate can force bits open transiently)

The map id m selects a row from the static per-map tensors built once in train() (lines 229–246). These are the only way map geometry enters the model:

tensorshapecontent
CELL[m](nmaps, 49) longmap-local cell index → absolute cell id r·G+c. Used to turn x[0:2] into absolute cells.
WALLIMG[m](nmaps, 49) float1.0 at wall cells (cells with yard.wall==True that are not gates). Open doorways are 0 here → visible in the render.
GC[m](nmaps, 3) longabsolute cell of each gate g (order = gate index = bit index)
LC[m], LW[m](nmaps, 2) long, (nmaps, 2, 3) floatlever cells; lever wiring as a 0/1 mask over gates (LW[m,l,g] = 1 iff pulling lever l flips gate g)
PC[m], PW[m](nmaps,) long, (nmaps, 3) floatplate cell; plate wiring mask (gates forced open while the crate sits on the plate)
CC[m], CD[m](nmaps,) long, (nmaps,) longchute cell and its allowed entry direction (0..3 = N S W E)
WALL[m], WN[m](nmaps, NW) long, (nmaps, 1) floatlist of wall cells (padded to NW = max wall count) and the count; used only for the pooled wall token
what the model does NOT get

No coordinates as numbers, no adjacency, no BFS. Wiring is given as masks (LW/PW); geometry only through the render (image path) and the wall pool. With --seewalls 0 (this recipe) the 1–5 permanently open non-gate doorways per map are present only implicitly: as zeros in the render's wall channel and as absences in the pooled wall token.

3 · CNNEnc.cnn → (B, 128, 7, 7) [lines 273–277]

Conv2d(8 → 32, kernel 3×3, padding 1)   # 8·32·9 + 32 = 2,336 params
ReLU
Conv2d(32 → 128, kernel 3×3, padding 1) # 32·128·9 + 128 = 36,992 params
ReLU                                     # out: (B, d=128, 7, 7)

Two 3×3 convs = a 5×5 receptive field on the 7×7 grid; every output cell sees its 2-neighbourhood. No pooling, no stride: spatial resolution is preserved so a query can still pick out one cell. (--cnndepth > 2 inserts extra 32→32 convs; the ledger's depth probe showed 3–4 hurt.)

4 · IMAGE READEnc._image_read, readout xattn → worker token w, crate token c [lines 308–320]

feat = cnn(render(x,m))                                  # (B,128,7,7)
fmap = feat.flatten(2).transpose(1,2) + imgpos[None]     # (B,49,128); imgpos: learned (49,128), init N(0,0.02²)
q    = (iquery + islot(arange(2)))[None].expand(B,-1,-1) # (B,2,128); iquery (2,128) N(0,0.02²), islot Embedding(2,128) N(0,1)
bound, _ = iattn(q, fmap, fmap)                          # nn.MultiheadAttention(128, 4 heads, batch_first)
w, c = bound[:,0], bound[:,1]                            # (B,128) each

Inside iattn (standard PyTorch): Q = q·W_q, K = fmap·W_k, V = fmap·W_v (one packed in-projection 128→384 + bias), split into 4 heads of 32, scores QKᵀ/√32 → softmax over the 49 cells → weighted sum of V → concat heads → out-projection 128→128 + bias. 66,048 params. Dropout 0.

this is the binding

Nothing tells query 0 where the worker is. It must learn, from the distance loss alone, an attention pattern that lands on the worker's cell in the feature map and reads out a vector from which position can be recovered downstream. Its imprecision is the "binding bottleneck" measured in the ledger (supervised aux +0.10). In this recipe: no aux, soft attention.

wall-pool caveat

Padding: WALL[m] is zero-padded to NW, so padded slots add pos(0) (cell 0's embedding) into the sum before dividing by the true count. Cell 0 is a corner cell; this is a small constant bias per map, identical for train/test.

6 · ASSEMBLE THE SEQUENCEInteg.forward, before the loop [lines 416–419]

zs   = enc(x, m) + role[0]          # start tokens, (B,11,128)  role: Embedding(3,128)
zg   = enc(g, m) + role[1]          # goal tokens
base = cat([zg, enc(x, m) + role[2]], 1)   # (B,22,128): goal + START ANCHOR (enc(x) recomputed, same values)
tok  = cat([zs, base], 1)           # (B,33,128)
cost = zeros(B)
0..10 zs = enc(x)+role0 (MOVES) 11..21 zg = enc(g)+role1 (fixed) 22..32 anchor = enc(x)+role2 (fixed)

Three copies of the same 11-token bag, distinguished only by the role embedding added to every token. The encoder is called three times per forward (twice on x, once on g); the two enc(x) calls are identical numbers.

7 · THE RECALL LOOP14 passes of one shared block [lines 420–422]

for t in range(14):
    z    = Block(tok)                                        # (B,33,128) full self-attention over all 33 tokens, no mask
    cost = cost + (z[:, :11] - tok[:, :11]).norm(dim=-1).sum(-1)   # L2 move length of each of the 11 STATE tokens, summed
    tok  = cat([z[:, :11], base], 1)                         # keep evolved state; RE-INJECT goal + anchor unchanged

Block = 4 × nn.TransformerEncoderLayer(d=128, nhead=4, dim_feedforward=256, dropout=0, activation=gelu, norm_first=True)

Per layer, with x the (B,33,128) input:

x = x + SelfAttn(LayerNorm₁(x))                       # MHA 4 heads × 32, QKV in-proj 128→384 (+bias), out-proj 128→128 (+bias)  66,048
x = x + Linear₂(GELU(Linear₁(LayerNorm₂(x))))         # 128→256→128 (+biases)  33,024 + 32,896
# LayerNorm₁,₂: 2·128 params each. Layer total 132,480. Four layers 529,920. The SAME four layers every pass.
  • What moves. Only tokens 0..10 carry state forward. Goal and anchor tokens are overwritten with their original values every pass, so the block sees an unchanging destination and origin (the "recall").
  • What is measured. After each pass, for each of the 11 state tokens, the Euclidean length of its displacement in R128; summed over tokens; summed over the 14 passes → one scalar per example. Goal/anchor displacements are never counted.
  • Depth. 4 layers × 14 passes = 56 layer applications; attention cost 33×33 per layer.
  • Flags off in this recipe. --norecall (would let goal drift), --decodehead (MLP on final state instead of the sum), --arrive/--Tmin/--Ttest (parking / anytime), --globalbase.

8 · OUTPUTone scalar [line 427]

D = softplus(scale) · cost        # scale: single learned parameter, init 0 → softplus(0)=0.693 at start

That's the whole head: no MLP, no bias. Positivity is guaranteed by construction (norms ≥ 0, softplus > 0). Any change in predicted distance must come from the state tokens moving more or less over the 14 passes.

9 · DATAHow pairs are made [make_yards line 195, build_pool line 208]

  • Maps. nmaps=200 yards. --split map: train m%4≠0 (150 maps), test m%4=0 (50 maps, unseen layout AND wiring). --split wire: 200 layouts × 2 wirings; train wiring A, test the same layouts with wiring B.
  • Pool. poolq=2000 random anchor states on random train maps; BFS from each anchor over the joint (worker, crate, bits) graph; for every distance value 0<dv≤Rmax=24 keep up to max(1, 40//#distinct_dv) targets → distance-stratified pairs (typically 25–40 per anchor → ~50–80k train pairs). Test pool: same procedure with a fixed rng on the test maps.
  • Batch. 128 uniformly random pairs from the pool each step. No curriculum in this recipe.

13 · KNOBS THAT CHANGE THIS PICTURE(all off in the reference recipe)

  • --enc factored|bmask: stages 2–4 replaced by w = pos(worker cell), c = pos(crate cell) (exact lookup, no perception). --enc marker: additive canvas + query attention instead of CNN.
  • --readout convspatial|convpool: replace the cross-attention read by per-agent spatial-softmax pooling / global mean pooling.
  • --seewalls 1: appends up to 5 doorway tokens pos(cell)+openkind (or a learned absent) → NTOK 16, sequence 48.
  • --markeraux w: adds CE(Linear(bound_i) → true cell) to the loss (supervised binding); --recon tied|slot, --hardattn: the unsupervised alternatives under test.
  • --bellman/--bellwarm/--ematarget/--bellrad: adds a self-consistency loss on unlabeled far pairs (length-extrapolation recipe); --arrive/--Tmin/--Ttest: parking + anytime budgets; --globalbase: adds softplus(gbase) once; --decodehead: MLP on the mean final state instead of the accumulated cost; --norecall: stop re-injecting goal/anchor.
  • Baselines (--iqeonly/--mrnonly/--symonly/--scalaronly) reuse the identical encoder (stages 1–5), then: a non-shared Block(d, heads, baselayers) over the 11 tokens → mean over tokens → Linear(128,128) → head (IQE / MRNFixed / L1 distance / MLP on concat).
